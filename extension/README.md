# BookmarkManager-bb收藏助手（浏览器扩展）

把当前页面一键收藏到你的 BookmarkManager 账号，支持选择目录与是否公开。
基于 Manifest V3，适用于 Chrome / Edge。

## 功能

- **弹窗收藏**：点扩展图标，编辑标题与描述、选择一级/二级目录、选择公开或私有，确认保存
- **随时新建目录**：目录下拉框右侧的 `+` 可直接新建一级/二级目录，无需切回后台
- **右键快捷收藏**：网页右键「收藏本页到书签库」，或链接右键「收藏此链接到书签库」，直接存到上次使用的目录
- **自动去重**：地址已收藏过会明确提示，不会重复写入
- **记住上次选择**：下次打开自动预选上次的目录与可见性
- **自动填充**：标题取当前标签页，描述尝试读取页面的 meta description

## 安装

1. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本 `extension` 目录
4. 建议把扩展固定到工具栏

## 启动服务端

扩展只是客户端，**服务端必须处于运行状态**，否则会提示「无法连接服务端」。

在项目根目录**双击 `start-server.cmd`** 即可：它会检测 3080 端口（已在运行就直接提示、不会重复启动），必要时自动编译，然后在当前窗口里启动服务。**窗口保持打开就是服务在运行，关掉窗口即停止。**

也可以手动启动：

```bash
cd src/BookmarkManager.Server
bin/Debug/net8.0/BookmarkManager.Server.exe
```

## 配置

首次点击图标会引导打开设置页，需要填两项：

**服务端地址** — 例如 `http://localhost:3080`。填完可点「测试连接」确认能连通（会显示站点名称）。

**账号** — 两种方式任选：

| 方式 | 说明 |
|---|---|
| 账号密码登录 | 直接用书签库的账号密码登录。会话令牌有效期 7 天，过期后在设置页重新登录即可 |
| API 令牌 | 在书签库后台「工具 → API 令牌」生成 `bmt_` 开头的令牌，粘贴保存。长期有效，适合长期使用 |

## 使用

- **收藏当前页**：点扩展图标 → 标题与描述已自动填好 → 选目录与可见性 → 点「收藏」→ 完成页显示保存到的目录与公开状态
- **快速收藏**：网页上右键 → 「收藏本页到书签库」（使用上次选择的目录与可见性）
- **换目录**：在弹窗里改选即可；目录下拉框的 `+` 能直接新建目录

## 关于「可见性」

- **公开**：出现在书签库的公开首页
- **私有**：仅自己可见

两点需要知道：

1. 账号有一个「新建节点默认公开」开关（在后台个人资料里设置），扩展首次打开时会按它预选
2. 如果所选目录（或其上级目录）本身是**私有**的，那么即使选了「公开」，后端也会自动按私有保存 —— 弹窗和通知都会提示这一点

## 常见问题

**提示「无法连接服务端」**
先确认服务端在运行 —— 在项目根目录双击 `start-server.cmd`（窗口别关）。再检查设置页里的服务端地址是否写对，可点「测试连接」验证。

**提示「登录已失效」**
会话令牌过期了（7 天）。在设置页重新登录，或改用长期有效的 API 令牌。

**点图标提示「这个页面不能收藏」**
浏览器内部页面（`chrome://`、扩展页、新标签页）没有可收藏的网址，切换到普通网页即可。

**扩展需要访问所有网站的权限吗？**
`host_permissions` 声明为 `http://*/*` 和 `https://*/*`，因为服务端地址可由用户配置。若不希望如此，可把它改成你的固定服务端地址，例如 `http://localhost:3080/*`。

## 目录结构

```
extension/
├── manifest.json     # MV3 清单：权限、右键菜单、弹窗与设置页入口
├── background.js     # 后台服务：注册右键菜单 + 快捷收藏 + 结果通知
├── api.js            # 共享模块：配置存储 + 开放 API 客户端（键名规整、错误封装）
├── popup.html/.css/.js     # 收藏弹窗
├── options.html/.css/.js   # 设置页（服务端地址、两种登录方式、账号信息）
└── icons/            # 16/32/48/128 图标（由 tools/make_extension_icons.py 生成）
```

## 依赖的服务端接口

扩展只调用开放 API 与鉴权接口，全部走 `Authorization: Bearer <token>`：

| 接口 | 用途 |
|---|---|
| `POST /api/login` | 账号密码换取会话令牌 |
| `GET /api/auth/me` | 校验令牌并读取账号信息 |
| `GET /api/init_status` | 设置页的连接自检 |
| `GET /api/v1/categories` | 读取分类树（一级 + 二级） |
| `POST /api/v1/add_link` | 收藏页面，返回 `{ id, created, is_public, url }` |
| `POST /api/categories` | 新建目录 |
